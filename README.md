# Tiernan Lindauer’s website

The live GitHub Pages site serves the static HTML and assets at the repository root. Project detail pages live in their own directories. The separate Next.js app below is a legacy experiment and is not part of the Pages deployment.

## Static site and search

- `npm run preview:site` serves the site at `http://127.0.0.1:8088` using Node’s standard library; no install is needed.
- `npm run search:index` regenerates `search-index.json` from public static pages and project cards. Run it after editing content and commit the updated index alongside those edits.
- `npm run test:site` checks search relevance, aliases, typos, category filters, project images, links, and language tags.

Search is available from the navigation on every page, with Ctrl/⌘ K or `/` shortcuts, and at `/search/`. It runs in the browser, loads the index on first use, and sends no queries to a server. Titles, aliases, languages, and descriptions are ranked above body text. Multiword searches require each meaningful word to match; spelling tolerance applies to project names and summaries.

Project image sources and demo labels are recorded in `public/projects/README.md`.

## Space environment tools

`space/` (hub), `debris/`, `van-allen/`, `star-tracker/` and `rf-link/` are static browser tools. Their data lives in `space/data/` and is generated by the scripts in `scripts/space/`:

- `build_catalog.py` compacts a GP/OMM catalog snapshot into `catalog.json`.
- `build_trapped_tables.py` and `build_field_grid.py` tabulate NASA AE8/AP8 and IGRF (L, B/B0) with NASA's `radbelt` package (needs gfortran); `pack_space_data.py` writes `ae8ap8.json`, `field-*.bin`, `field.json` and `nist.json`.
- `make_radiation_fixture.py` writes the direct-model reference points used by `tests/space.test.cjs`.
- `build_star_catalog.py` compacts HYG v4.1 for the optical tracker. The [catalog attribution](space/data/stars.LICENSE.md) links to the pinned input and license.
- `calibrate_rf_thresholds.cjs` measures the RF link simulator's required Eb/N0 for each modulation and coding with its own receiver (1% frame loss on a static channel). Paste its output into `rf-link/budget.js` after changing the receiver.

`npm run test:site` checks the browser models against direct AE8/AP8 calls and CREME96 dose, TLE round-trips, conjunction screening, image-only attitude recovery from simulated detector pixels, and the RF link's CCSDS coding, pass geometry, link budget and end-to-end decoding.
