Photolib

A private, local photo library for Windows. Find photos by description or person, browse dates and places, organize albums, and spot duplicates. Search runs on your computer with a bundled offline model.

Python Rust JavaScript

Download Windows setup · View source

Photolib keeps your photo library on your own computer. Describe a photo instead of remembering its filename, find people with face recognition, and combine date, place, folder, and person filters.

The desktop app includes favorites, ratings, albums, reverse image search, and duplicate detection. It supports incremental indexing and cached previews when an original drive is offline. The Windows installer includes the image/text model; face recognition weights are an optional one-time download.
